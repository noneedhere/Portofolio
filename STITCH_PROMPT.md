# Google Stitch Design Prompt --- Fullstack Developer Portfolio

## Role

Act as a senior product designer and visual UI/UX designer specializing
in premium developer portfolios.

Design a complete, responsive personal portfolio website for a **Junior
Fullstack Web Developer / Fresh Graduate**.

The design should feel custom-designed, premium, editorial, modern, and
highly intentional. Do **not** produce a generic developer portfolio
template.

------------------------------------------------------------------------

# 1. Reference Direction

Use the two attached reference images as visual inspiration, but do not
copy them literally.

### Reference A --- Hero Composition

Take inspiration from the first reference for:

-   Large oversized typography in the hero
-   Minimal navigation at the top
-   Strong black/white visual contrast
-   A large portrait integrated into the hero composition
-   Portrait positioned partially over/behind typography
-   Small professional introduction on the left
-   Social media links arranged vertically on the right
-   Minimal pill-shaped buttons
-   Large whitespace
-   Editorial / art-direction feel

The large developer name should function as a visual graphic, not merely
as a normal heading.

### Reference B --- Overall Website System

Take inspiration from the second reference for:

-   Dark premium visual identity
-   Deep black / near-black backgrounds
-   Dark emerald / green accent color
-   Large bold typography
-   Rounded section containers
-   Strong section separation
-   Modern card layouts
-   Subtle gradients and glow
-   High-contrast text
-   Contemporary agency-style visual language
-   Structured content blocks
-   Smooth, purposeful motion

Combine the **hero composition of Reference A** with the **dark visual
language and section treatment of Reference B**.

Do not simply merge the two screenshots. Create a coherent new design
specifically for a Fullstack Web Developer portfolio.

------------------------------------------------------------------------

# 2. Design Concept

Core concept:

> **Editorial Developer Portfolio × Premium Digital Studio**

The portfolio should feel like a combination of:

-   Personal brand website
-   Modern digital agency
-   Editorial portfolio
-   High-end developer landing page

The visual identity should communicate:

-   Technical capability
-   Creativity
-   Professionalism
-   Confidence
-   Modern frontend expertise
-   Strong attention to detail

Avoid a typical portfolio made from repeated centered cards and generic
gradients.

------------------------------------------------------------------------

# 3. Visual Identity

## Color System

Primary background:

-   Near-black
-   #080808
-   #0D0D0D

Secondary surfaces:

-   #111111
-   #151515
-   #1B1B1B

Primary text:

-   White / near-white

Secondary text:

-   Muted gray

Accent:

-   Emerald / vivid green

Use the green accent selectively for:

-   Availability status
-   CTA highlights
-   Active navigation states
-   Small decorative elements
-   Important metadata
-   Hover states
-   Subtle glow effects

The green should be an accent, not the dominant page color.

------------------------------------------------------------------------

# 4. Typography

Use a modern sans-serif typeface with excellent readability.

Recommended direction:

-   Inter
-   Geist
-   Manrope
-   Satoshi
-   Plus Jakarta Sans

Use strong typographic contrast:

-   Very large display typography for hero
-   Bold section headings
-   Medium-weight body text
-   Small uppercase metadata labels
-   Compact navigation typography

Typography should feel editorial rather than corporate.

Use responsive typography with fluid sizing where appropriate.

------------------------------------------------------------------------

# 5. Global Layout

Use a spacious desktop-first visual composition while maintaining a
mobile-first implementation strategy.

Desktop:

-   Maximum content width around 1200--1400px
-   Generous horizontal margins
-   Large vertical spacing
-   Asymmetric compositions
-   Full-width visual sections where appropriate

Mobile:

-   Preserve visual hierarchy
-   Stack content naturally
-   Reduce oversized typography
-   Convert horizontal layouts into vertical layouts
-   Keep interactions touch-friendly
-   Never allow horizontal overflow

Use a consistent grid system throughout the website.

------------------------------------------------------------------------

# 6. Navigation

Create a minimal floating/sticky navigation inspired by Reference A.

Desktop navigation:

Left:

-   Small availability status pill
-   Green status indicator
-   Text such as "Available for New Opportunities"

Center:

-   Work
-   About
-   Experience
-   Contact

Right:

-   Primary CTA: "Let's Talk ↗"

Use a clean pill-based visual style.

Navigation should remain lightweight and unobtrusive.

On mobile:

-   Logo/name
-   Hamburger button
-   Full-screen or floating mobile menu
-   Smooth open/close animation

------------------------------------------------------------------------

# 7. Hero Section

This is the most visually important section.

Create a large editorial hero composition.

## Hero structure

### Top

Minimal navigation.

### Main visual layer

Display the developer's name as very large typography.

Example:

**YOUR NAME**

Use a combination of:

-   Outline typography
-   Solid typography
-   Different font weights
-   Large scale
-   Slight overlap

The name can extend beyond normal content boundaries while remaining
responsive.

### Portrait

Place a professional developer portrait prominently in the center or
slightly off-center.

The portrait should feel integrated into the composition rather than
placed inside a conventional card.

Possible treatment:

-   Transparent/background-removed portrait
-   Subtle monochrome or high-contrast treatment
-   Soft green ambient glow
-   Image partially overlapping the oversized typography
-   Image extending beyond the hero content grid

Do not use a circular profile picture.

### Left information block

Position a compact introduction toward the lower-left area.

Example structure:

**FULLSTACK WEB DEVELOPER**

"Building modern web experiences with clean interfaces, scalable
architecture, and thoughtful user experiences."

CTA:

**View My Work ↗**

### Right social links

Create vertically stacked pill buttons:

-   GitHub
-   LinkedIn
-   Instagram
-   Email

Each should have:

-   Icon
-   Label
-   Hover animation

The social buttons should visually resemble the small pill buttons in
Reference A.

------------------------------------------------------------------------

# 8. Hero Animation

Use sophisticated but restrained motion.

On page load:

1.  Navigation fades/slides in
2.  Large name reveals with staggered motion
3.  Portrait smoothly fades/slides upward
4.  Introduction appears afterward
5.  Social links appear sequentially

Possible effects:

-   Text reveal
-   Masked typography
-   Slight image parallax
-   Subtle floating decorative elements
-   Smooth opacity/transform transitions

Avoid:

-   Excessive bouncing
-   Random motion
-   Overly dramatic zoom
-   Continuous distracting animations

Respect `prefers-reduced-motion`.

------------------------------------------------------------------------

# 16. Interaction Design

Every interactive element should have intentional states.

Define:

-   Default
-   Hover
-   Focus
-   Active
-   Disabled

Recommended micro-interactions:

-   Buttons slightly translate on hover
-   Arrow icons move subtly
-   Cards reveal a green glow
-   Technology icons scale slightly
-   Images gently zoom
-   Navigation links show active state
-   Social pills respond to hover

Keep interaction duration around 200--500ms for normal UI interactions.

------------------------------------------------------------------------

# 17. Scroll Experience

Create a smooth storytelling experience as the user scrolls.

Recommended sequence:

1.  Hero
2.  About
3.  Skills / Stack
4.  Featured Projects
5.  Experience
6.  Education
7.  Contact
8.  Footer

Sections should reveal progressively as they enter the viewport.

Use subtle scroll-triggered animations.

Do not make every element animate independently.

------------------------------------------------------------------------

# 18. Responsive Behavior

### Desktop

Preserve:

-   Oversized typography
-   Asymmetric layout
-   Large portrait
-   Horizontal navigation
-   Side social links

### Tablet

-   Reduce display typography
-   Adjust portrait size
-   Simplify grid
-   Maintain asymmetric composition where possible

### Mobile

Transform the hero into a vertical composition:

1.  Navigation
2.  Oversized name
3.  Portrait
4.  Developer title
5.  Description
6.  CTA
7.  Social links

Do not simply shrink the desktop layout.

Redesign the composition for mobile.

-   Keyboard accessibility

-   Reduced-motion support
-   Touch-friendly controls
